# Sample media (optional, freely-licensed)

The benchmark harness normally uses synthetic media generated by
`generate_test_media.sh` (testsrc2 + sine), which is reproducible and
license-free. If you want to benchmark "real world" content, drop files into
these folders:

```
inputs/
├── mp4/     <- default location the harvester scans (find_mp4_input)
└── mp3/     <- default location for audio (find_mp3_input)
```

**The harness picks any files it finds**, so copying a sample here (or into
`inputs/mp4`/`inputs/mp3`) is all you need — no config change.

Below are suggested, freely-licensed sources. Always check the license of the
exact file you download.

## MP4 (video) — CC-licensed / public-domain test clips

| File | Source | License | Rough size |
| ---- | ------ | ------- | ---------- |
| Big Buck Bunny (Blender film) | `download.blender.org/peach/` | CC-BY 3.0 | 30 MB–1 GB |
| Sintel (Blender film) | `download.blender.org/durian/` | CC-BY 3.0 | 100 MB – 2 GB |
| Tears of Steel (Blender film) | `download.blender.org/mango/` | CC-BY 3.0 | 100 MB – 2 GB |
| Elephants Dream (Blender film) | `download.blender.org/ed/` | CC-BY 2.5 | 50–300 MB |
| Big Buck Bunny (raw mp4, verified) | `archive.org/details/BigBuckBunny_124` | CC-BY 3.0 | ~120 MB (720p) |

Blender mirror files are under `https://download.blender.org/<film>` (folders:
`peach`, `durian`, `mango`, `ed`, `cosmoslaundromat`, `spring`,
`tearsofsteel`). Most are packaged as `.zip` — download and unzip, or pick a
small, short file for fast test loops.

## Quick download examples

```bash
# Big Buck Bunny 720p, raw mp4 from archive.org (verified live, CC-BY 3.0)
curl -Lo inputs/mp4/sample_bunny.mp4 \
  https://archive.org/download/BigBuckBunny_124/Content/big_buck_bunny_720p_surround.mp4

# Apollo 11 radio program, mp3 from archive.org (public domain, verified live)
curl -Lo inputs/mp3/sample_apollo11.mp3 \
  "https://archive.org/download/FootStepsMoon/Footsteps%20on%20the%20Moon%20-%20Side%20A.mp3"
```

> Tip: for trends that are comparable across machines, prefer the synthetic
> media — real-world clips make timing depend on the specific file's encoder
> and bitrate, not just your hardware.
